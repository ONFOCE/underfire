# 图片放置说明

游戏会自动加载 `img/` 目录下的图片，**文件名就是图片的「定位坐标」**——文件名等于对应文本的 id，代码据此精准对位，零歧义。

## 规则

- 路径格式：`img/<id>.webp`（若用 `.png`/`.jpg`，改代码里 `showImage` 的后缀即可）
- 尺寸建议：**1280×720（16:9 横幅）**
- 没生成的图片会自动隐藏，不报错、不错位——可以一张张慢慢补。

## 生成提示词模板

每张图都用**同一套风格前缀** + 对应场景文本作为内容描述，保证整部作品画风统一：

> 电影感写实插画，暗黑战争废墟题材，冷色调（深褐、炭灰、暗橙），胶片颗粒质感，氛围压抑沉重，无文字、无字幕、无水印，横幅 16:9。
>
> 场景内容：<把对应 id 的那段游戏文本贴在这里>

生成后按上表命名（如 `d1.webp`、`r_dog.webp`）放进本目录即可。
